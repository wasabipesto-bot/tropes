# Trope Log

A personal TVTropes-style catalogue built on a media log. Each trope has a page
describing it and listing every logged work where it appears; each work has a
page listing its tropes, ratings and links. Associations are proposed by a
language model that reads the log and the source material, then verified by hand.

Status: planning. Nothing runs yet.

- `docs/SPEC.md` is the design and product spec (from the Claude Design handoff).
  Where the spec and anything else disagree, the spec wins unless `docs/ROADMAP.md`
  records a deliberate change.
- `docs/ROADMAP.md` is the implementation plan: stack proposal, architecture,
  auth, phases, cost estimates and the decisions still open.
